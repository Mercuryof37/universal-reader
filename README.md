# 通用文档阅读器

**把你自己的文档变成一本可双语对照、可朗读、可批注的电子书。**

打开网址就能用，不需要注册、不需要安装。

> **文档不出浏览器。** 解析、存储、批注全部在你自己的电脑上完成，
> 没有服务器存你的文件，也没有上传。可以放心导入私密文档。

```
访问地址：https://REPLACE-WITH-YOUR-PAGES-DOMAIN.pages.dev
```

## 快速开始

1. 用浏览器打开上面的网址
2. 把文档**直接拖进页面**，或点击「选择文件」
3. 开始阅读

支持四种格式：

| 格式 | 扩展名 | 说明 |
|---|---|---|
| Markdown | `.md` `.markdown` `.mdx` | 标题、列表、引用、代码块都会被正确识别 |
| 纯文本 | `.txt` `.text` `.log` | 自动识别 UTF-8 / GBK / UTF-16 编码 |
| PDF | `.pdf` | 文字版可直接读；扫描版可 OCR |
| 电子书 | `.epub` | 按章节顺序解析 |

**浏览器要求**：Chrome / Edge 119 以上、Firefox 121 以上、Safari 17.4 以上。
版本过低时 PDF 无法导入，页面会给出提示。

## 导入文档

### 拖拽或选择

把文件拖到页面上任意位置，或点击「选择文件」。可以一次选多个，会依次导入。

### 导入失败时

页面顶部会显示具体原因。常见情况：

| 提示 | 含义 | 怎么办 |
|---|---|---|
| 「是扫描版（图片型）PDF」 | 整本都是图片，没有文字层 | 用下面的 OCR 功能，或换一份文字版 |
| 「没有可读文本（实测编码：…）」 | 文件是空的，或内容无法识别 | 确认文件本身有内容 |
| 「不支持的文件格式」 | 扩展名不在支持列表里 | 先转换成支持的格式 |
| 「未能提取出任何文本内容」 | 解析成功但内容为空 | 同上 |

导入成功后，文档库里每条记录会显示**字数、段落数、源文件名**，
纯文本还会显示**识别到的编码**（如「编码：GB18030 / GBK」）。

## 阅读

### 滚动阅读

长文档用**虚拟滚动**：只渲染你看到的部分，几万段的文档也不会卡。
滚动流畅度与文档长度基本无关。

### 目录跳转

点顶部工具条的目录图标，会自动列出文档里的所有标题。
Markdown 的 `#` 标题、纯文本的「第X章」都会被收进目录。

### 记住阅读位置

关闭后重新打开同一文档，会**自动回到上次读到的位置**。

### 段落级朗读按钮

鼠标移到任意段落上，左侧会出现一个朗读按钮，点它只读这一段。

## 双语对照

点顶部工具条的**语言图标**开关译文。

### 三种翻译引擎

| 引擎 | 需要配置吗 | 特点 |
|---|---|---|
| **浏览器内置翻译** | 不需要 | Chrome 138+ 自带，无需密钥。不支持时该选项为灰色 |
| **DeepL** | 需要（见下） | 质量高，尤其擅长中欧互译 |
| **OpenAI** | 需要（见下） | 长句与语境理解更好 |

> 如果部署时没有配置云端翻译，应用会**自动使用浏览器内置翻译**，
> 不需要你手动切换。

### 只翻译你看的部分

应用**不会**一次性翻译全文，而是**滚动到哪里翻译到哪里**（前后各留几段缓冲）。
这样既快又省额度。已翻译的段落会缓存下来，重新打开文档不会重复翻译。

想一次翻完，可以在设置里点「翻译全文」。

### 双语布局

四种模式，按需切换：

| 布局 | 效果 |
|---|---|
| 上下对照 | 原文在上，译文在下（默认） |
| 左右对照 | 左右两栏并排 |
| 只看原文 | 隐藏译文 |
| 只看译文 | 隐藏原文 |

## 语音朗读

### 开始朗读

- 点顶部工具条的**播放按钮**，从当前位置开始读
- 或者点某一段左侧的朗读按钮，只读那一段
- 按 **空格键**也可以播放/暂停

### 自动连读

读完一段会自动读下一段。可以在设置里关闭。

### 声音设置

在设置面板里可以调：

- **朗读语言**（普通话 / 英语 / 日语等）
- **语速**（0.5 ～ 2 倍）
- **音色**（取决于你的操作系统）
- **合成引擎**

### 两种合成引擎

| 引擎 | 优点 | 缺点 |
|---|---|---|
| **浏览器原生** | 免费、离线可用、无需配置 | 音色取决于操作系统，Windows 和 macOS 差别明显 |
| **云端合成** | 音色质量高、跨设备一致 | 需要部署方配置密钥 |

默认「自动」：有云端配置就用云端，否则用浏览器原生。

## 批注

### 高亮与笔记

1. 用鼠标**选中一段文字**
2. 浮出的工具条上选择：**高亮** / **记笔记** / **提问** / **打标签**
3. 批注出现在右侧栏里

### 五种高亮色

在批注侧栏里点颜色圆点即可改色。

### 搜索与筛选

批注侧栏支持：

- 按**原文或笔记内容**搜索
- 按**类型**筛选（高亮 / 笔记 / 提问 / 标签）
- 点击批注**跳回原文位置**

### 导出

底部两个按钮可导出全部批注：

- **JSON** —— 保留完整结构，便于程序处理或备份
- **Markdown** —— 带原文引用，适合直接当读书笔记分享

### 关于「失锚」

如果文档被重新解析后位置对不上，批注**不会被删除**，
而是标记为「原文已改动，无法定位到具体位置」。你的笔记不会丢。

## 扫描版 PDF 的 OCR

扫描版 PDF（整本都是图片）没有文字层，无法直接阅读。
应用内置了浏览器端 OCR 可以识别出文字。

### 怎么用

1. 导入扫描版 PDF，页面会提示「检测到扫描版 PDF」
2. 选**识别语言**（简体中文 + 英文 / 繁体 / 日文 / 韩文 / 纯英文）
3. 选**识别页数** —— **建议先用「前 10 页」试跑**
4. 点「开始识别」

### 需要知道的

| 事项 | 说明 |
|---|---|
| **速度** | 每个页面需要几秒到几十秒，取决于页面大小和你的设备 |
| **首次更慢** | 第一次使用需要下载语言包（中文约 22MB），且**需要联网** |
| **建议用电脑** | 手机 CPU 弱，而且切到后台会被浏览器降频 |
| **单页失败不影响整体** | 失败页会被跳过并列出页码，其余页面照常保存 |
| **空白页自动跳过** | 扫描书里的隔页、插图页会被识别并跳过，省时间 |

进度条会显示**已用时间**和**预计剩余时间**，据此判断整本要跑多久。

### 如果 OCR 效果不理想

可以在电脑上用专业工具离线处理，再把结果导入本阅读器：

```bash
ocrmypdf -l chi_sim --force-ocr 输入.pdf 输出.pdf
```

处理后的 PDF 带文字层，导入后即可双语对照与朗读。

## 离线使用与安装到桌面

### 离线阅读

**首次访问并刷新一次之后**，应用就可以离线使用：

- 断网后打开网址，页面正常显示
- 已导入的文档**照常阅读**
- 扫描版 PDF 的 OCR 如果用过一次，语言包也已缓存，离线仍可用

底部会出现「已离线」提示条，告诉你这是正常状态而不是网站坏了。

> **为什么需要刷新一次**：离线能力由浏览器的 Service Worker 提供，
> 它需要先完成安装才能接管页面。

### 安装到桌面（可选）

安装后从桌面图标启动，**没有浏览器地址栏**，用起来像本地软件。

| 浏览器 | 操作 |
|---|---|
| Chrome / Edge | 地址栏右侧会出现「安装」图标，点它 |
| Android Chrome | 菜单 →「添加到主屏幕」 |
| iOS Safari | 分享按钮 →「添加到主屏幕」 |

### 更新

有新版本时底部会提示「有新版本可用」，点「立即更新」即可。

**不会自动刷新**——这是刻意的：你可能正在读长文档，
自动重载会丢掉滚动位置和正在进行的操作。

## 阅读设置

点顶部工具条的**齿轮图标**打开设置面板。

| 设置 | 作用 |
|---|---|
| **字号** | 12 ～ 32 px |
| **行距** | 1.2 ～ 3 倍 |
| **版心宽度** | 480 ～ 1100 px，控制每行多长 |
| **字体** | 衬线（书卷感）/ 无衬线 |
| **主题** | 宣纸 / 米黄 / 夜读（含暗色模式） |

设置会**自动保存**，下次打开还是你调好的样子。

## 遇到问题怎么办

### 先做这一步

**按 `Ctrl + Shift + R` 强制刷新。**
很多"改了没生效"的问题都是浏览器缓存了旧版本。

### 常见问题

| 现象 | 原因与处理 |
|---|---|
| PDF 无法导入，提示缺某个 API | 浏览器版本过低。升级到 Chrome/Edge 119、Firefox 121 或 Safari 17.4 以上 |
| 扫描版 PDF 打开后一片空白 | 该 PDF 是纯图片且没有文字层。点「开始识别」用 OCR |
| 导入后提示「是扫描版」但没有 OCR 按钮 | 刷新页面重试；若仍不行，请反馈 |
| txt 打开后是乱码或空白 | 文档编码比较特殊。看文档库里的「编码」标签，若显示「可能有误」请反馈 |
| txt 段落全挤在一起 | 该文件用单换行分段且没有空行。目前按空行分段，会认为是一整段 |
| 翻译报「未配置翻译端点」 | 部署方未配置云端翻译。在设置里把引擎切成「浏览器内置」 |
| 朗读没有声音 | 检查系统音量；浏览器可能拦截了自动播放，先点一下页面再试 |
| 离线后打不开 | 首次访问后需要刷新一次才能启用离线。见上方说明 |
| 批注显示「原文已改动」 | 文档重新解析后位置对不上。批注不会丢，但需要手动确认位置 |

### 反馈问题时请附上

1. **浏览器和版本**（地址栏输入 `chrome://version`）
2. **按 F12 → Console** 的报错截图
3. 问题文件的**格式与大致大小**

导入失败时页面会给出可复制的诊断信息，直接贴出来最有帮助。

## 关于你的数据

### 数据存在哪里

| 数据 | 存放位置 |
|---|---|
| 导入的文档 | 你浏览器的 IndexedDB |
| 批注 | 同上 |
| 阅读进度 | 同上 |
| 翻译缓存 | 同上 |
| 阅读设置 | 同上（localStorage） |

**服务器上没有你的任何数据。** 部署的只是一堆静态文件。

### 这意味着什么

✅ **隐私**：可以放心导入私密文档、工作资料、个人笔记

⚠️ **不会跨设备同步**：每台设备的书库是独立的。
在电脑上导入的书，手机上看不到；各人的批注互不影响。

⚠️ **清除浏览器数据会丢失**：清理浏览器缓存/站点数据时，
已导入的文档和批注会一起被清空。

### 建议

- 重要的批注**定期导出**（批注侧栏底部有导出按钮）
- 想换设备阅读，把**原始文件**发到那台设备重新导入
- 不要把这个网址当作唯一的笔记存储

## 当前不支持的功能

以下是已知的功能缺口，按实际影响排序：

| 缺失 | 影响 | 临时办法 |
|---|---|---|
| **PDF 页眉页脚未过滤** | 每页的页眉、页码会变成正文，污染阅读流 | 无 |
| **PDF 双栏排版会串行** | 教材、论文的左右栏可能被读成一行 | 无 |
| **正文全文搜索** | 只能搜批注，不能搜正文 | 用浏览器 `Ctrl+F`（仅能搜已渲染的部分） |
| **跨设备同步** | 见上 | 各设备分别导入 |
| **全量数据导出** | 无法一次性备份所有文档 | 逐个导出批注 |
| **书签/收藏** | 只能靠批注标记位置 | 用「笔记」代替 |
| **Markdown 表格渲染** | 表格会作为普通文本显示 | 无 |
| **手机端 OCR 体验差** | CPU 弱、后台降频 | 在电脑上完成 OCR |

> 这些不是"可能有问题"，而是**确定做不到**。
> 开发计划见仓库根目录的 `HANDOFF.md`。
